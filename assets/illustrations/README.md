# 論文 Wiki 插圖

原創生成的透明 PNG，可放在網站的論文卡片或簡報中。奶油色、湖水藍、柔珊瑚粉和奶油黃搭配深藍綠線條。

| 檔案 | 適用場景 |
| --- | --- |
| [paper-search.png](paper-search.png) | 論文資料庫、文獻搜尋、Google 搜尋量 |
| [market-reaction.png](market-reaction.png) | 投資人注意力、公告後股價反應。插圖只描繪概念，研究數據另以圖表呈現。 |
| [institutional-news.png](institutional-news.png) | 機構投資人、金融新聞、終端資料 |
| [linked-research.png](linked-research.png) | 相關論文、提問紀錄、跨論文比較 |

配色建議：奶油底 `#FFF8E9`、湖水藍 `#68BBD0`、珊瑚粉 `#F3A1B0`、奶油黃 `#F4DB83`、深藍綠 `#24556C`。
